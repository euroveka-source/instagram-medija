# instagram-medija

Vieša medžiagos saugykla „Vežimėlių kampelis" socialiniams tinklams.

Čia dedami tik tie failai (JPEG, MP4), kurie skelbiami Instagram arba Facebook
per Meta Graph API – API reikalauja viešo failo adreso, o GitHub Pages jį
suteikia.

Kiekvienas failas pasiekiamas adresu:

    https://euroveka-source.github.io/instagram-medija/<failas>

Failai laikomi tik iki paskelbimo ir po jo – kaip archyvas. Nieko privataus
čia nededama.
